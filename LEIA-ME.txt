VISTORIAS TÉCNICAS — NUVEM COMPARTILHADA V12

1. Publique todos os arquivos deste ZIP na raiz do mesmo projeto Vercel.
2. Mantenha o armazenamento Blob PRIVADO e as variáveis já utilizadas:
   BLOB_READ_WRITE_TOKEN e VISTORIA_ACCESS_HASH (SHA-256 da chave de acesso).
   Nunca coloque o token Blob no HTML ou compartilhe o token com usuários.
3. Abra o aplicativo, aceite a atualização se aparecer e conecte com sua chave.
4. Em cada outro aparelho, abra o MESMO endereço e informe a MESMA chave uma vez.
   A chave fica lembrada até sair, limpar os dados do navegador ou trocar a chave.
5. Todos com a chave têm acesso de leitura, edição e exclusão. Compartilhe-a
   somente com as pessoas autorizadas. Não há contas individuais nesta versão.

A lista de vistorias, fotos e dados de cada relatório é sincronizada a cada
20 segundos com o aplicativo aberto/visível e após salvar. Há também o botão
Sincronizar agora. Sem internet, o app guarda as alterações no aparelho e tenta
novamente ao reconectar. Com o app fechado, a nuvem mantém os dados já enviados;
não é possível garantir novos envios em segundo plano pelo navegador.

Exclusões se propagam para os outros aparelhos; a cópia local vai para a lixeira.
Edições simultâneas diferentes são preservadas como versões para comparação.
Use uma aba por aparelho para editar. Aguarde o estado de sincronização antes
de fechar. Cópias antigas continuam acessíveis nos controles de backup: recupere
uma vez as que desejar compartilhar. Registros antigos com IDs distintos podem
aparecer como duplicados e devem ser conferidos antes de excluir.

O catálogo de equipamentos e preferências locais não fazem parte desta
sincronização; as informações preenchidas dentro das vistorias fazem.
O histórico de revisões fica na nuvem e não é removido ao esvaziar a lixeira.
Esta atualização reutiliza o serviço existente: não configura automaticamente
as variáveis ou o armazenamento de um projeto novo. Os arquivos precisam ser
publicados para que a alteração entre em funcionamento.
